# Mini-Sticks Player

**Open the customisation screen:** https://christiankudeba.github.io/mini-sticks-player/

Change the player's number, name, jersey colours and logo, his height, strength and face, and play all 58
moves, in the browser. "Save player" saves the settings as one file a game can read.

**Download the whole package** (the player for a game as GLB and FBX, every clip, the textures and
the documents, one zip): https://github.com/ChristianKudeba/mini-sticks-player/releases/latest/download/MiniSticksPlayer.zip

The screen bundles three.js (MIT licence) and glyph atlases drawn from a font under the SIL Open
Font License 1.1: see `THIRD_PARTY_NOTICES.md` and `OFL.txt`.
